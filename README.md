# 📊 Dashboard Ejecutivo Valorizado por EESS

Dashboard interactivo para el monitoreo del valorizado de medicamentos por Establecimientos de Salud (EESS) y Microred, desarrollado por **AVengineers Agency**.

## 🌐 Ver en línea
👉 **[https://tu-usuario.github.io/dashboard-valorizado-eess/](https://tu-usuario.github.io/dashboard-valorizado-eess/)**

## ✨ Características
- 📋 Filtros por **Microred**, **Establecimiento**, **Año** y **Mes**
- 💊 KPIs independientes: **SIS**, **Intervención Sanitaria**, **Ventas**, **Exonerados**, **SOAT** y **DN**
- 📊 Gráficos interactivos (Barras y Donut)
- 📄 Tabla paginada con todos los registros
- 📁 **Carga dinámica de Excel** — cualquier usuario puede cargar su propio reporte `.xlsx` sin necesidad de servidor
- 🔒 100% privado: los datos nunca salen del navegador

## 🚀 Cómo usar
1. Abre el enlace de GitHub Pages
2. El dashboard carga con datos precargados
3. Para actualizar datos: presiona **"Cargar Otro Excel"** y selecciona tu plantilla SISMED

## 📦 Tecnologías
- HTML5 + CSS3 + JavaScript
- [Chart.js](https://www.chartjs.org/)
- [SheetJS (xlsx.js)](https://sheetjs.com/)
- [Font Awesome](https://fontawesome.com/)
